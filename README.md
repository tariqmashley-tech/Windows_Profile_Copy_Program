# Windows_Profile_Copy_Program
A program I wrote to copy a Windows profile to another
A program I wrote to copy a Windows profile The company I currently work for is currently working in a hybrid environment where some services are run from a local server and others are run in a cloud environment. One of the services ran locally is the Active Directory service. A majority of employees have local AD (Active Directory) Windows profiles stored on a local on-premises server. My manager, who is also the company IT Director, would like all Windows profiles to be stored in Microsoft Entra instead so we can repurpose the local server for other company-related tasks. The direct way to complete this is to have each user log into their computer using their M365 company email and password, as opposed to their local AD account. The issue with this is that the user will have to essentially rebuild their profile from scratch: reconfiguring their software settings, potentially reinstalling software (if the installed software was profile-based), and basically rebuilding their Windows profile environment. To avoid users taking too much time to rebuild their Windows profile, I created a program that copies profile-specific files and folders from their local AD accounts to their newly created Entra Windows profiles. Configurations, settings, preferences, as well as personal files and folders are all copied over to the new Entra profile. My program ensures that the user has to do little to no profile setup after signing into their Entra profiles. The automation of this process will reduce the amount of downtime users have after signing into their Entra profiles, allowing for miminal workflow interruption and continued company productivity. I created my program in C# using Rider. It integrates the use of a subprogram called RoboCopy to copy over the profile data. You simply enter the path of the local AD user folder then enter the destination where you want the data to be copied, which would be the newly created Entra user folder, then execute the program. A status window runs the entire time showing the progress of each file and folder that is copied. At the end, a final results screen shows what was copied and if any files or folders were unable to be copied. During the copying process, any files or folders unable to be copied are accompanied by an error message stating why (insufficient privilege, folder path does not exist, etc.). Once complete, the program instructs to log out and back in to the Entra profile to confirm the profile was successfully copied.
